# 💸 Split-It: An Android Expense Manager

Welcome to **Split-It**! This is a Splitwise-inspired Android application built to simplify group expenses and debt management. This is our first official Android project, developed as a collaborative effort to master mobile engineering and version control.

---

## 🚀 The Vision
Managing shared costs between friends or suitemates can get messy. Our app allows users to log expenses in real-time, track individual balances, and "settle up" without the headache of manual math.

### Core Features
* **Group Tracking:** Organize expenses by trips, dinners, or household bills.
* **Smart Splitting:** Support for equal splits and custom percentage-based splits.
* **Live Balance:** A dedicated dashboard showing who owes you and who you need to pay back.
* **Optimized Settlements:** (In Progress) Using a simplified matching logic to minimize the total number of transactions within a group.

---

## 🛠 Tech Stack
* **Language:** Kotlin / Java
* **UI:** Jetpack Compose (Modern Declarative UI)
* **Database:** Room (SQLite) for local data persistence
* **Architecture:** MVVM (Model-View-ViewModel) for clean, maintainable code
* **VCS:** Git & GitHub for team collaboration
